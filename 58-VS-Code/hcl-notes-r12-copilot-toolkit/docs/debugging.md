| 環境 | 建議先在 DEV／TEST 驗證；PROD 啟用條件、負責人與期限另行核准。 |
| Client | 識別使用者觸發事件與前端文件狀態；目的地待確認，不以大量 Messagebox 作為 logger。 |
| Server | 識別 Agent／排程／Web 及執行身分情境；使用適合非互動程序的目的地，實際路徑待確認。 |
| 日誌欄位 | 建議包含時間及時區、嚴重度、環境別、Client／Server、元素／程序、非敏感追蹤碼、錯誤編號、可用的行號及遮蔽後訊息。 |
| 錯誤追蹤 | 同次操作以非敏感追蹤碼關聯；不要直接用文件內容、Notes 名稱或機密識別值。錯誤行號須與當時程式版本核對，不能假定等於 DXL 檔案行號。 |
| 資料保護 | 密碼、權杖、連線字串、個資及文件內容不得原樣記錄；錯誤文字也需檢查。例：`token=[REDACTED]`。允許欄位、日誌讀取權限及保存期限待確認。 |
| 關閉行為 | 關閉 debug 只停止詳細診斷，必要錯誤紀錄仍需保留；不能把必要錯誤處理包在 debug 條件內。 |
| 業務一致性 | 開關不得改變計算、驗證、權限、寫入、交易順序或成功／失敗結果。日誌寫入失敗不得覆蓋原始錯誤；處理方式待設計。 |
