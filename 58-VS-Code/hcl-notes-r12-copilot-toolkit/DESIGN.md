## 待盤點項目

| 項目 | 既有規範 | 應記錄的證據 |
|---|---|---|
| 字體 | 待確認 | 字型、字級、粗細、標題／內文用途及顯示環境 |
| 色彩 | 待確認 | 文字、背景、強調、錯誤狀態；有來源才記色碼 |
| 間距 | 待確認 | 區塊、欄位、標籤與按鈕間距；沿用該介面的實際單位 |
| 欄位標籤 | 待確認 | 名稱、冒號、對齊、位置及多語需求 |
| 按鈕 | 待確認 | 文案、順序、主要／次要操作及停用狀態 |
| 必填提示 | 待確認 | 符號、說明文字與提示時機，不只依靠顏色 |
| 驗證訊息 | 待確認 | 顯示位置、觸發時機、修正指引及保留輸入方式 |
| 操作順序 | 待確認 | 閱讀、Tab 焦點、儲存／送出／取消及確認步驟 |

## 依介面判斷

- Notes 原生：依 Form／Subform、欄位、表格、Action 等實際元素盤點；不可直接套用 CSS、DOM、瀏覽器元件或 px 間距假設。
- 傳統 Domino Web：確認 HTML 產生方式、既有 CSS／JavaScript 與瀏覽器範圍後才引用規範，不假設與 Notes 呈現相同。
- XPages：確認 XPage／Custom Control、既有主題與相關資源後才引用規範，不假設已採用特定 UI 框架。
- 多介面共用設計：分別記錄行為及畫面證據，不能用其中一種測試代表全部。
